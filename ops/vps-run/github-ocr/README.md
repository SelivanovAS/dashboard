# Модели на GitHub Actions

Схема 31.10.2026: парсер ХМАО сохраняет HTTP-сессию суда на российском VPS,
а `github_captcha.yml` вызывает OpenRouter на GitHub-hosted runner.
Старый финский туннель не является автоматическим резервом этого режима.

## Устройство

`/etc/court-github-ocr/config.json` с `{"enabled": true}` включает обмен.
Без файла сохраняется прежний транспорт. Некорректный файл останавливает
поиск, а не переводит его незаметно на старый маршрут. Настройка действует
только для уже разрешённого флагом пилота ХМАО.

Парсер создаёт случайный Unix socket в `/run/court-github-ocr`, затем вызывает
workflow_dispatch для `SelivanovAS/dashboard`, workflow `github_captcha.yml`,
ref `main`. Токен API читается из отдельного root-only файла
`/etc/court-github-ocr/github-token`, не из региональных env. В GitHub уходят
только ID запроса и срок подключения. Ожидание готовности ограничено 120 с и
остатком общего дедлайна с резервом 60 с. После готовности начинается прежний
бюджет поиска 180 с. Число попыток, модели и предел четырёх вызовов сохранены.

Runner подключается к российскому серверу как `court-gh-ocr`. ForceCommand
разрешает только `github_captcha_bridge.py` и ID из 32 hex-символов. Shell,
port forwarding, агент и терминал недоступны. Парсер проверяет UID подключившегося
процесса и точный ID запуска GitHub. Поздний запуск не найдёт закрытый socket.
Картинка и код передаются по SSH в памяти; в Git, артефакты и логи не пишутся.
Worker допускает только две закреплённые модели, PNG и прежний промпт.

Secrets ХМАО: `OCR_SSH_PRIVATE_KEY`, `OCR_SSH_KNOWN_HOSTS` и существующий
`OPENROUTER_API_KEY`. Variable: `OCR_SSH_HOST`. Приватный SSH-ключ даёт только
доступ к существующему сеансу капчи; ключ OpenRouter на VPS для этого режима
не требуется. Host key берётся через уже доверенное административное соединение.

Установка SSH-пользователя, root-owned authorized_keys, sshd Match User и
tmpfiles.d выполняется отдельно от пакета. Каталог socket: root:court-gh-ocr,
0750; отдельный socket — 0660. Правило tmpfiles восстанавливает каталог после
перезагрузки. Файл API-токена — root:root 0600. При замене токена права сохранять.

## Пересказы

`ops/vps-run/vps_env.sh` задаёт `CM_SUMMARY_GENERATION=0`: пригодные полные
тексты сохраняются без попытки модели и без новой `retry_after`. Готовый кэш
переиспользуется. GitHub replay явно задаёт `CM_SUMMARY_GENERATION=1`.
Прямой вызов пересказа тоже соблюдает запрет после проверки кэша.
Старые ошибки и отсрочки не стираются массово: перед переходом нужно проверить
остаток очереди. Отказ по источнику/реквизитам не становится разрешённой задачей.

## Проверка и возврат

После штатной установки пакета: `python3 scripts/probe_github_captcha.py <отчёт>`.
Это одна настоящая попытка поиска (с обычными резервами), без изменения картотеки
и без рассылки. Скрипт удаляет ключи моделей и задаёт недоступный финский транспорт
в своём процессе. Успех — принятие кода и распознанная выдача, а не зелёный workflow.
`probe_summary_models.yml` проверяет реальный пересказ вымышленного акта без доставки.

До успешных проверок старую службу туннеля не останавливать. Возврат транспорта:
`enabled: false` в конфигурации OCR возвращает прежний путь, если он ещё доступен.
Генерация пересказов на VPS остаётся выключенной; очередь обрабатывает GitHub.
Возврат программы — штатным пакетом через `program_release.py`, с сохранением данных.
