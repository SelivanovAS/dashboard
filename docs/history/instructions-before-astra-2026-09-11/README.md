# История инструкций до аудита Astra

Снимки сделаны 11.09.2026 перед приведением входных инструкций к единому виду:

- [AGENTS.before.md](AGENTS.before.md) — прежняя карта Codex, 1 521 строка.
- [CLAUDE.before.md](CLAUDE.before.md) — прежняя карта Claude, 2 147 строк.

Это исторический справочник для точечного поиска решений и разборов инцидентов.
Внутри намеренно сохранены старые названия, неверные обобщения и расходящиеся
описания запуска. Они **не являются действующими инструкциями**; текущее правило
или поведение нужно сверять с [AGENTS.md](../../../AGENTS.md) и затронутым кодом.
Не загружать обе карты целиком при каждом начале работы.

Исходный текст сохранён. Относительные Markdown-ссылки получили префикс
`../../../`, чтобы открываться из архивной папки. SHA-256 исходников указан
в каждом снимке; исходные файлы также доступны в Git до аудита.

[Отчёт об аудите](../../Аудит_инструкций_Astra_2026-09-11.md) описывает исправления
и объём проверки. Архив находится вне `docs/technical/*.md`: устаревшие номера
строк в историческом тексте не следует автоматически переписывать под новый код.
