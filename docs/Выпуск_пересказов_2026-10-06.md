# Выпуск пересказов актов — 06.10.2026

## Состав

По поручению пользователя выпускается цепочка **Apodex 1.1 Mini Free →
GigaChat 3 Pro → Claude Haiku 4.5**. Полный текст акта проходит подготовку,
проверку заключительной части и доступных реквизитов. Контекст не обрезается.
Тематический отказ GigaChat переводит запрос к Claude. Очередь сохраняет
незавершённые пересказы независимо от уведомлений; повтор дописывает анализ
карточки без повторного объявления акта. Данные обоих треков и архивов сохраняются.

## Проверки перед публикацией

- Python 3.12, эталон: **3327 passed, 16 subtests passed**.
- До начала выпуска все четыре локальных checkout совпадали с `origin/main`;
  VPS был на тех же исходных коммитах, без незавершённых изменений.
- GitHub Actions Variables проверены: моделей, переопределяющих выбранную
  цепочку, нет. У Башкортостана и Тюмени задан `LLM_PROVIDER=openrouter`;
  у ХМАО и Урала используется дефолт workflow.
- В проверенных `env.*` VPS LLM-ключи и переопределения моделей отсутствуют;
  рабочий путь LLM — GitHub replay. Расписания и исполнители не переключаются.

## Ключи по территориям

Проверено наличие имён Secrets, не их значения. Живой вызов GigaChat 3 Pro
и Haiku проверялся ранее только ключами эталонного репозитория.

| Территория | OpenRouter | GigaChat | Claude |
|---|---|---|---|
| ХМАО | есть | есть | есть |
| Урал | есть | отсутствует | есть |
| Башкортостан | есть | есть | есть |
| Тюмень | есть | отсутствует | отсутствует |

Пользователю предложено добавить недостающие ключи. До этого Урал использует
Apodex → Haiku, Тюмень — Apodex; пропуск резерва без ключа предусмотрен кодом.

## Граница выполнения

Документ включён в подготовленный выпуск. Коммиты, региональные проверки,
CI/Pages и установка VPS будут зафиксированы после выполнения соответствующих
шагов. Первый штатный прогон после установки пока не проверен. Тестовая
рассылка и массовое пересоздание готовых пересказов в выпуск не входят.
