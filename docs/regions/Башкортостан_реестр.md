# Реестр судов Республики Башкортостан

> Документ фиксирует региональную работу и подготовку общего кода. Конфиг
> Башкортостана и новые функции импорта, президиума и времени суда отсутствуют
> в исходном коммите эталона `1a943a7f`; эта публикация включает только документацию.
> [Границы снимка и выпуска](../Сверка_документации_2026-09-13.md).

Исходная проверка реестра: 11.09.2026; описание охвата кода уточнено 13.09.2026.
При исходной проверке поиск Сбербанка с VPS сработал во всех 46 местных
судах из Excel: получены первые страницы по 25 строк. Все 23 судебных
присутствия сопоставлены с общими базами `srv_num=1` своих 18 основных судов.
Поиск 6 КСОЮ требует проверочного кода; карточки вводятся через дампы выдачи.
Это подтверждение состава и начального поиска, а не полноты банковского портфеля.

## Состав и происхождение

Источник: `Копия БашГОСБ_Список судов для Приложения_v0.xlsx`, один лист
«Суд общей юрисдикции», строки 5–73. Все 69 строк сверены с XML исходного Excel.
SHA-256: `e52be4551a6f24c2099fe78e08f2f78a8e3b60573b3a3ed58be0cc00cbb2d36a`.

- 45 городских, районных и межрайонных судов первой инстанции.
- 23 постоянных судебных присутствия (СП) на сайтах основных судов.
- Верховный суд Республики Башкортостан — апелляция по районным делам.
- Шестой КСОЮ добавлен по поручению пользователя; отдельной строки в Excel нет.

В исходном охвате 11.09.2026 — 70 справочных записей с кассацией и 47 объектов:
45 первой инстанции, одна апелляция, один КСОЮ. Присутствия входят в общие
базы основных судов и не создают повторные поисковые задания. Этот исходный
справочник не включал президиум. В текущем `bashkortostan.py` добавлен его
кассационный раздел на том же домене ВС РБ: всего 48 настроенных разделов
в 47 судах. Автопоиск президиума ограничен первой страницей, ручной дамп также
поддержан. Самостоятельный мониторинг карточек мировых участков и дел ВС РБ
как первой инстанции в охват не включён.

[JSON](bashkortostan_courts.json) сохраняет исходные ID BPM, ID ГАС, адреса,
пометки СП/ЭИД, URL/гиперссылки, связи с основным судом, результаты проб,
каталоги зданий и источники доказательств. [CSV для сверки](bashkortostan_courts.csv)
имеет кодировку UTF-8 с BOM. Настройка Python:
`scripts/court_monitor/regions/bashkortostan.py` (локальная разработка, файл не включён в этот выпуск).

## Как проверялся доступ

Первые диагностические запросы с обычным User-Agent `curl` не воспроизводили
запросы парсера. На Mac 45 из 46 исходных адресов дали пустой ответ, один —
таймаут; на VPS все 46 исходных адресов дали сброс соединения. Повтор
канонических адресов без браузерных заголовков также не доказывал недоступность
для рабочего парсера. Эти серии сохранены в JSON как история диагностики.

После установки тех же `User-Agent`, `Accept`, `Accept-Language`, что использует
`netutil.session`, с VPS получены:

| Проверка | Результат |
|---|---|
| Раздел делопроизводства всех 46 судов | 46 HTTP 200, реальные названия судов, 805 ссылок на карточки в расписаниях |
| Формы гражданского поиска | 43 HTTP 200 с реальными G1/G2-полями, `delo_id/new/delo_table/srv_num`; CAPTCHA нет |
| Три оставшиеся формы | HTTP 429: Благоварский, Благовещенский, Туймазинский; при последующем поиске все три успешно ответили |
| Первая страница поиска «Сбербанк» | 46 HTTP 200 без CAPTCHA, по 25 ссылок, всего 1 150 строк |
| Каталоги зданий 18 судов с СП | Получены реальные записи подразделений в `srv_num=1` |

После появления 429 сделана пауза, запросы поиска выполнены последовательно
с интервалом 3 секунды. URL поиска построены непосредственно
`CourtConfig.search_url()`. Дополнительных страниц эта серия не запрашивала.

Канонические адреса `*--bkr.sudrf.ru` вернули HTTP 301 на исходные
`*.bkr.sudrf.ru`, затем были прочитаны реальные страницы. Runtime хранит
принятое в общем коде каноническое представление; исходные ссылки Excel сохранены.
Время каждого запроса, профиль заголовков, итоговый URL, HTTP-результат и SHA тела
записаны в `network_probes`. Этот успешный результат относится к VPS; повторная
полная серия с браузерными заголовками на Mac не проводилась.

Для [формы 6 КСОЮ](https://6kas.sudrf.ru/modules.php?name=sud_delo&srv_num=1&name_op=sf&delo_id=2800001&new=2800001)
отдельный GET подтвердил проверочный код и параметры `delo_id=2800001`,
`new=2800001`, `delo_table=g33_case`, `G33_PARTS__NAMESS`, `srv_num=1`.
[Одна карточка с актом](https://6kas.sudrf.ru/modules.php?case_id=24413318&case_uid=268d4cf1-f089-48be-b3c8-44b86ad5d164&delo_id=2800001&name=sud_delo&name_op=case&new=2800001&srv_num=1)
получена без CAPTCHA. Автопоиск КСОЮ выключен обоими флагами, чтение известных
карточек включено. Часовой пояс суда — `Europe/Samara`; местные суды и расписание
территории остаются в `Asia/Yekaterinburg`, UTC+5.

## Названия и спорный ID

Бижбулякский суд в строке 37 Excel назван районным; живой сайт называет его
межрайонным. Runtime использует межрайонный, исходное районный сохранено как
alias. Подтверждённые прежние подписи также сохранены для Зилаирского районного,
Кумертауского городского и Белорецкого городского судов. Для семи районных
судов Уфы принимается сокращённое имя без `г. Уфы`, с обязательным маркером
Башкортостана в полном имени. Неподтверждённые прежние названия не выдумывались.

В **C8** сохранено `03RS0040_Akiar`, хотя URL, контакты и каталог подразделений
связывают Акъяр с Зилаирским судом, основной код которого в **C48** — `03RS0043`.
Код `03RS0040` в **C45** принадлежит Дюртюлинскому суду. Точное новое значение
составного ID Акъяра без подтверждения владельца справочника не назначено.
Связь строки 8 с основным судом устанавливается по URL и подтверждённому
подразделению, а не по спорному префиксу. ID BPM, ID ГАС, BUILDING_ID и УИД дел
не подменяют друг друга.

## Начальный набор и оставшиеся проверки

Пользователь согласовал загрузку первых страниц, дальнейший добор — вручную
операторами через дампы. Поэтому в Башкортостане ручной импорт доступен для
всех настроенных разделов (48 с президиумом); отметка свежести закрытой выдачи применяется к источникам
с `search_gated`. Это не изменение гейтов поисковых запросов местных судов.

При проверке 11.09.2026 из 1 150 строк первых страниц штатные парсеры с `keep_all_roles=True` выделили
1 083 строки настоящего Сбербанка. Отсеяны 66 строк дочерних организаций в
первой инстанции и одна строка «Сбербанк Страхование» в апелляции. Это кандидаты
до чтения карточек и карточных правил приёма. Обычный режим поиска только
банка-ответчика выделяет 49 строк первой инстанции и 24 апелляции; он не заменяет
первичный импорт обоих треков. Указанные сайтами 95 073 результата относятся ко
всем страницам, годам и ролям и не являются числом активных дел банка.

Ограничения исходной проверки и дальнейший контроль:

1. Чтение карточек и корректный приём обоих треков; недоступность карточки
   отражать по её настоящей причине. Исходная диагностическая серия карточки
   первой инстанции и апелляции не загружала; последующее наполнение и проверки
   описаны в [отчёте пилота](Башкортостан_внедрение_2026-09-11.md).
2. Контрольный банковский список по судам и СП; первую страницу не считать
   доказательством полноты. Добрать остальные страницы согласованным ручным вводом.
3. Спорный ID Акъяра у владельца справочника, сохранив прежнее значение.
4. Связи первая инстанция → апелляция → кассация и отсутствие смешения с
   одноимёнными судами других республик.

Этот документ не подтверждает деплой, включение расписания и отправку
уведомлений. Результаты публикации и наполнения фиксируются отдельно.
