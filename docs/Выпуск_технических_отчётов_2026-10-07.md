# Выпуск технических отчётов · 07.10.2026

## Состав

Личный Telegram получает технический результат парсинга и выпуска дайджеста.
Юридический дайджест сохраняется в приложении; персональный Web Push и явно
выбранная групповая рассылка сохраняют свои правила. Отчёт показывает полноту
парсинга, очереди, события, фактические модели пересказа, кэш и причины резервов,
а также отдельные результаты Git, Pages и Web Push.

Исполнитель сообщает о сбоях, восстановлении и существенных результатах дневной
дочитки. Контроль отсутствия завершённого прогона работает через существующую
службу доставки после 10:00 по Екатеринбургу. Новый таймер не устанавливается.
Подробный [контракт отчётов](Технические_отчёты.md) описывает доказательства
успеха, повторные попытки и границы диагностики.

## Подготовка

Проверки эталона на Python 3.12: **3571 passed, 16 subtests passed**.
Дополнительно проверены shell-синтаксис, YAML workflow, якоря документации и
отображение макета Telegram на узком экране. Тесты выполнялись с заглушками
транспорта и временными данными; реальная рассылка для проверки не запускалась.

Перед выпуском сверены все четыре checkout и актуальные удалённые ветки.
Региональные данные, настройки Workers, расписания и собственные файлы
территорий сохраняются. Пользовательские каталоги `exports/` и `outputs/`
не входят в выпуск.

## Статус публикации и установки

На момент подготовки этого коммита публикация, региональный перенос и
установка на VPS ещё выполняются. Итоговые SHA, CI, Pages, проверки VPS и
граница первого штатного отчёта будут зафиксированы после получения фактических
результатов. Зелёные локальные тесты не являются подтверждением живой доставки.
