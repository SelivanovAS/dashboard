# Сокращение тестов — 18 октября 2026

Проверен и изменён текущий checkout `dashboard`, исходный коммит `166d260`.
Изменены только тесты, их общий вспомогательный модуль и правила сопровождения.
Код продукта, данные, региональные копии и workflow не изменены.

Удалено **3 243 строки из тестовых файлов (7,8%)**.
Новый общий `js_support.py` содержит 36 строк; с его учётом чистое
сокращение составляет 3 207 строк. Фикстуры не выносились в другие
файлы ради уменьшения счётчика. Время запуска практически не изменилось.

Предварительный ориентир 30–50% **не достигнут**. При подробной проверке большая
часть похожих сценариев оказалась защитой разных юридических последствий,
ошибок идентификации дел и отказов доставки. Они сохранены. Количество сценариев
не сокращалось ради квоты: таблицы убирают повторение кода, сохраняя входы и ожидания.

## Изменения

- Удалена 151 некритичная проверка: CSS, значки, размещение элементов, точные
  формулировки подсказок, исторические анонсы, оформление логов и детали реализации.
- Удалены пять дублей: четыре дополнительных проверки версий PWA и один повтор
  поведения `SMART_SKIP_CASES`. Точная сверка уточнила первоначальную оценку:
  согласованность `?v` и `CACHE_VERSION` проверялась в **пяти** местах, теперь —
  только в [test_versions.py](../scripts/tests/test_versions.py). Проверки
  сохранения офлайн-данных при смене версии — отдельное поведение и сохранены.
- 142 тестовых функции перенесены в таблицы, включая 85 сценариев дайджеста.
  Исходные имена сохранены в идентификаторах параметров. Разные исходы дел,
  даты, стороны, фильтрация и ограничения формата проверяются по-прежнему.
- 26 проверок отдельных полей объединены по результату одного разбора карточки
  или поиска. Сохранены исходные утверждения, изменена только общая подготовка.
- Девять проверок исходников или их важных частей заменены проверками поведения:
  отложенное обновление, последовательность загрузок, возобновление при закрытии
  шторок, миграция кэша, сохранение соседней территории и уведомление о новых данных.
- Проверка полноты дайджеста, вычислявшая ожидаемые номера через внутренние
  фильтры самого продукта, заменена существующим сценарием всех типов событий
  с независимыми ожиданиями. Проверки рендера текущего снимка данных сохранены.
- Общие чтение исходника и извлечение JS-функций вынесены в небольшой
  [js_support.py](../scripts/tests/js_support.py). Используются прежние pytest и Node.

[Точная таблица изменений](test_reduction_2026-10-18.csv) содержит 334
исходных тестов. Для каждого объединённого, параметризованного или заменённого
теста указаны **существующие собранные pytest-идентификаторы** замены.
Удаление некритичной проверки обозначено отдельно, без заявления о замене.

## Сохранённая защита

Наборы импорта и полной очереди, прав доступа, жизненного цикла профилей,
раздельного хранения bank-events, транзакций парсинга и доставки, блокировок
и региональной изоляции сохранены. В `mac_*` удалены только перечисленные
служебные и косметические проверки; испытания настоящих Bash-драйверов остались.
Проверка различия «Решение» и «Определение» сохранена как юридически значимая.

Статические проверки критичной связи компонентов, для которых пока нет
равноценной поведенческой замены, сохранены. Удаление такой проверки само по
себе не улучшает набор. Для новой сквозной обвязки основного прогона потребуется
отдельная работа, а не массовое удаление существующей защиты.
