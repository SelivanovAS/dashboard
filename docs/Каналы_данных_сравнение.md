# Каналы судебных данных вместо капчи — сравнение и рекомендация

> Итоги разведки **14.07.2026 (вечер)** по плану из
> [Легитимные_каналы_вместо_капчи_контекст.md](Легитимные_каналы_вместо_капчи_контекст.md).
> Casebook — на паузе (ответ про API нескоро); здесь — все альтернативы.
> Метод: только публичные страницы (ничего не регистрировал, форм не отправлял);
> каждый факт с URL. Пробы доступности — фактические HTTP-ответы на 14.07.2026.

## Главное

Задача канала — **только суды, закрытые проверочным кодом** (пилот —
Академический р/с Екатеринбурга; 20 судов ХМАО кодом не закрыты и продолжают
парситься бесплатно). Объём мал: 1–3 суда × (поиск + карточки) ≈ **60–200
запросов/мес** — это меняет экономику: подойдут минимальные пакеты посредников
и даже бесплатные тарифы.

**Рекомендация — три параллельных хода, от дешёвого к платному:**

1. **Бесплатно, сегодня:** оставаться на baseline (детект кода + 🩺-алерт уже
   в проде, Академический пилот вручную) и отправить два запроса:
   письмо в Судебный департамент про официальный `api.sudrf.ru` (черновик ниже)
   и вопросы в юрдеп про СПАРК/Контур.Фокус (чек-лист ниже). Оба хода «может
   выстрелить, стоит ноль».
2. **Если нужен канал быстро:** тест **Юрайт (you-right.ru)** — единственный
   посредник, чей продукт совпадает с нашим сценарием слово в слово («мониторинг
   исков против юрлица в СОЮ», движение дела, апелляции/кассации, акты,
   iCal-календари), с прозрачным прайсом (мин. пакет 1000 запросов/мес =
   4 900 ₽/мес), нормальным ООО и кейсами уровня КАМАЗ/Банк России. Перед
   договором — этап 0 на тестовом доступе (чек-лист внизу).
3. **Casebook** остаётся основным утверждённым планом — при ответе про API
   вернуться к нему; архитектура `source`-dispatch готова и подходит любому
   каналу из этого документа.

⚠️ Честная оговорка для решения: **все посредники добывают данные парсингом
ГАС «Правосудие» сами** — ни один не публикует соглашения с Суддепом.
«Легитимность» для банка = лицензионный договор с поставщиком данных (обход
защит, если он есть, — риск поставщика, не наш). Поставщиков, рекламирующих
«работаем без капчи» как фичу (api-parser.ru), из шорт-листа исключил.

## 1. Официальный `api.sudrf.ru` (ГАС «Правосудие»)

**История.** Запущен в январе 2018 как бесплатный сервис машиночитаемых
открытых данных по СОЮ: «поиск и отображение открытых данных судов общей
юрисдикции», обновление раз в сутки
([Roem, 25.01.2018](https://roem.ru/25-01-2018/267073/api-pravosudie/)).
Уже в феврале 2018 заявки висели без ответа, техподдержка отвечала «доступ
временно приостановлен — перенос БД» (комментарии там же). ⚠️ Заметка «перенос
БД, доступ приостановлен» из прошлой разведки — это **новость 2018 года**, а не
текущий статус.

**Текущий статус (пробы 14.07.2026):**

| Проба | Откуда | Результат |
|---|---|---|
| `https://api.sudrf.ru/` | Mac (RU, Сургут) | HTTP 403, штатная заглушка ГАС «запрос некорректен (B)» |
| `https://api.sudrf.ru/` | US-инфраструктура | HTTP 404 (TLS не рубится — geo-блока на уровне хендшейка нет) |
| `https://api.sudrf.ru/docs` | Mac (RU) | HTTP 404 (страница ГАС) |
| `https://api.sudrf.ru/docs` | веб-архив 21.02.2024 | «заблокирован по соображениям безопасности (G)» для US-краулера — в 2024 путь ещё жил за geo-фильтром |
| `https://techportal.sudrf.ru/` | Mac (RU) и US, два замера | TCP/TLS проходят, ответа нет (таймаут 35–60 с) — портал техподдержки лежит |

Веб-архив: корень отдавал 302 в 2018, 404 с 2022 — публичной формы
регистрации/документации давно нет. Свежих (2024–2026) свидетельств выдачи
ключей не нашлось; поддержка исторически: **api@sudrf.ru**, **info@cdep.ru**
(упоминаются в документации посредников).

**Вывод.** Инфраструктура жива, но сервис публично «спит». Письмо отправить
стоит (бесплатно, черновик ниже) — но строить план на нём нельзя: вероятность
и срок ответа непредсказуемы.

## 2. Юрайт — you-right.ru (ООО «ЮРАЙТ»)

Профиль совпадает с нашей задачей: «отслеживание поданных в отношении своего
юрлица либо контрагента иска на сайте суда общей юрисдикции», «синхронизация
движения дела от даты поступления до передачи в архив», «мониторинг подачи
апелляций и кассаций», импорт документов с распознаванием, календари JSON/iCal
([/api-gas-pravosudie](https://you-right.ru/api-gas-pravosudie),
[/api](https://you-right.ru/api)).

- **Цены** ([/api](https://you-right.ru/api)): 1000 запр./мес = 4 900 ₽/мес,
  далее ступени до 30 000 запр. = 135 000 ₽/мес; при годовой оплате −17%
  (1000 запр. = 49 000 ₽/год). «Объекты мониторинга не тарифицируются» —
  платят только за запросы. **Наш объём (60–200 запр./мес) — минимальный пакет
  с большим запасом.**
- **Договор:** ООО «ЮРАЙТ», ИНН 7721787940, ОГРН 1137746211976, Москва
  ([/kontakty](https://you-right.ru/kontakty)); «не публичная оферта» — B2B
  договор + «Регламент ИТС»; связан с группой WiseAdvice. Публичные кейсы:
  КАМАЗ, Банк России, «Вертолёты России», СК «Гелиос»
  ([/keysy](https://you-right.ru/keysy)).
- **Тест:** «Попробовать бесплатно» / «Заказать демо» — заявка через форму
  (условия теста не публикуются; заявку подаёт юрист).
- **Открытые вопросы к демо:** поиск по **названию** (публично заявлен только
  ИНН — а в карточках СОЮ ИНН сторон обычно нет: как матчат?); отдаётся ли УИД;
  лаг относительно ГАС; публичной техдокументации нет — запросить.

## 3. api-assist.com

Два продукта по СОЮ (источник — bsr.sudrf.ru / сайты судов):

- **`sudrf_api`** ([документация](https://api-assist.com/documentation/sudrf-api.txt)) —
  справочники + **поиск** (суд, регион, инстанция, судья, категория, даты,
  произвольная текстовая строка — участника можно искать текстом) + детали дела.
- **`sudrf_custom_api`** ([документация](https://api-assist.com/documentation/sudrf-custom-api.txt)) —
  карточка по известному URL дела. Ответ богатый: номер и **УИД**, суд, судья,
  категория, участники (с ИНН/ОГРН где указаны), **события движения** (дата,
  время, зал, результат), документы/акты, исполнительные листы, **обжалования**.

**Цена:** «бесплатный тариф — 200 запросов в месяц без каких-либо условий»
([/api/sudrf](https://api-assist.com/api/sudrf)) — на пилот из 1 суда может
хватить целиком; платные тарифы — по переписке (support@api-assist.com).

**Минусы:** юрлицо/ИНН оператора нигде не опубликованы (для закупки банком —
стоп-фактор до выяснения); эндпоинт буквально `/parser/…` — скрейп-посредник;
SLA/лаг не заявлены. Как **бесплатный технический тест данных** (сравнить
карточку с нашим парсером) — самый дешёвый вариант из всех.

## 4. newdb.net

«API ГАС Правосудие для юридических лиц»
([/yur/pravosud](https://newdb.net/yur/pravosud),
[документация](https://newdb.net/docs/gas/)): единственный с явным **поиском по
наименованию компании** (`pravo_search`: наименование/номер дела/судья/категория),
карточка `pravo_cases_details`, поиск по текстам актов `act_text_search`;
заявлено «при каждом запросе — обращение к первоисточнику» (реальное время).
**Цена:** 2 ₽/запрос, пакет от 1000, 100 бесплатных тестовых.
**Минус:** оператор — **ИП** (ОГРНИП 319508100254288), договор — публичная
оферта; для банковской закупки вероятно не пройдёт, но как второй кандидат
на техтест — годится.

## 5. CyberJustice («Единое API») / archeon.io

Продукт «Лаборатории Павла Жукова»: kad.arbitr + mos-gorsud + **региональные
sudrf.ru (СОЮ)** + мировые суды Москвы/МО; «ежесуточный мониторинг изменений по
делу», **webhook-уведомления**, поиск «по номеру дела и UID» — единственный,
где УИД заявлен явно ([archeon.io/data/cyberjustice](https://archeon.io/data/cyberjustice/)).

- **Цены:** годовые пакеты по объектам мониторинга: до 100 дел/ИНН —
  99 000 ₽/год; до 500 — 199 000; до 1000 — 299 000.
- **Договор:** ИП Жуков П.О., ИНН 501849988146, без НДС; оферта, оплата по
  счёту; SLA 97%, при сбоях внешних источников допускается деградация до 7 раб.
  дней ([оферта](https://archeon.io/license)).
- **Минусы:** публичной документации API нет (только по запросу);
  исторический лендинг `www.cyberjustice.ru` **не резолвится ни из US, ни из RU**
  (проверено с Mac 14.07) — живой продукт представлен только на archeon.io;
  основной домен cyberjustice.ru теперь занят другим продуктом («AI Юрист»).

## 6. api-parser.ru / parser-api.com — исключён

Функционально аналог api-assist (поиск + карточки, JSON), но публично
рекламирует «работает через http запросы, **без капчи**» — прямой маркер обхода
защиты судов. Для банка репутационно токсично; цены и реквизиты не публикуются.
Сайт с Mac и c US-инфраструктуры отдаётся с таймаутами. Не рекомендую.

## 7. apiportal.ru — не оператор, а маркетплейс

«Портал API» (ООО «РНД СОФТ», Ростов-на-Дону): витрина ~1200 API, судебные
карточки в каталоге — это продукты Юрайта, API Assist, Api-parser и
**Casebook/Pravotech** (у последней публичный файл методов API 3.0:
[methods-casebook-api-3.0.docx](https://pravo.tech/documents/casebook-api/methods-casebook-api-3.0.docx) —
пригодится, когда Casebook ответит). Договор и деньги — напрямую с поставщиком;
как самостоятельный канал не рассматривается.

## 8. СПАРК-Интерфакс (проверить наличие у банка)

Модуль **«Судебная практика»**: СОЮ и мировые судьи с 2015 г., карточка дела с
хронологией, «данные о делах и решениях, судебных актах и графиках заседаний»,
постановка дел на мониторинг
([features/arbitration-practice](https://spark-interfax.ru/features/arbitration-practice),
[quick-search СОЮ](https://spark-interfax.ru/quick-search/poisk-i-proverka-po-sudam-obshchej-yurisdikcii)).
Функционально — ближайший к нашей задаче из «банковских» сервисов.

**Но:** СПАРК сам предупреждает — «в решениях СОЮ отсутствует точная
идентификация участников», привязка к компании **вероятностная**; API — SOAP/XML
50+ методов, но публичной документации судебных методов нет; вебхуки не
упомянуты; цены — по запросу (ориентир сторонних обзоров: 65–200+ тыс. ₽/год).
Всё ключевое выясняется только изнутри подписки — см. чек-лист вопросов.

## 9. Контур.Фокус (проверить наличие у банка)

Единственный с **публично документированным REST-методом по СОЮ**:
`GET /api3/generalCourtCases` (ключ, ИНН/ОГРН, роль, пагинация) — номер дела,
категория, участники и роли, суд, судья, **этапы движения и результат**
([новость 06.05.2025](https://focus.kontur.ru/site/news/56239-rasshirili_dannye_o_sudax_obshhej_yurisdikcii_v_api_fokusa),
[каталог методов](https://focus-api.kontur.ru/)). Мониторинг списков — pull:
`monList` / `monitoringGetChanges` (вебхуков нет).

**Дисквалифицирующий факт для нас:** «Сведения обновляются **каждые три
недели**», глубина — 3 года
([features/courts](https://focus.kontur.ru/site/features/courts)); дат заседаний
и текстов актов в публичном описании нет. Годится как страховочный/обогащающий
канал («не пропустили ли дело вообще»), не как источник ежедневных событий.
Ориентир цен API (партнёр): 96–315 тыс. ₽/год; `generalCourtCases`, судя по
справке Контура, — отдельно подключаемая опция договора.

## 10. Casebook (основной план, на паузе), baseline и 3a

- **Casebook:** утверждённый план в силе; этап 0 по скриншотам пройден отлично
  (события = дословные формулировки ГАС, УИД, связка инстанций, ИНН участников —
  см. [хэндовер](Легитимные_каналы_вместо_капчи_контекст.md)). Ждём ответ про
  API-доступ; публичный файл методов API 3.0 — см. раздел 7.
- **Baseline (в проде):** детект кода + 🩺-алерт + ручная проверка капча-судов.
  0 ₽. Пилот Академического — вручную. Это точка отсчёта: любой платный канал
  должен быть лучше неё на нашем мизерном объёме.
- **3a cookie-reuse:** `probe_captcha.py --cookie` готов; не запрещён, но
  отставлен — вернуться, только если юрист готов вводить код руками раз в
  N дней, и сначала замерить срок жизни cookie (инструкция в
  [старом хэндовере](Проверочный_код_капча_контекст.md)).

## Черновик обращения в Судебный департамент (официальный API)

Кому: **api@sudrf.ru**, копия **info@cdep.ru** (адреса из документации
интеграторов; при недоступности — форма на techportal.sudrf.ru, когда портал
оживёт). Отправляет юрист от своего имени (или от банка — на его усмотрение).

> **Тема:** Доступ к API ГАС «Правосудие» (api.sudrf.ru) — запрос о статусе
> сервиса и порядке подключения
>
> Здравствуйте!
>
> В январе 2018 года Судебный департамент открыл сервис api.sudrf.ru для
> получения открытых машиночитаемых данных о делах судов общей юрисдикции.
> Прошу сообщить:
>
> 1. Действует ли сервис в настоящее время и выдаются ли ключи доступа?
> 2. Каков порядок подключения для юридического лица (заявка, документы,
>    сроки)? Предусмотрена ли плата?
> 3. Где доступна актуальная техническая документация (методы, форматы,
>    ограничения по частоте запросов)?
> 4. Если сервис приостановлен — планируется ли возобновление и есть ли
>    официальный альтернативный канал машиночитаемого доступа к данным о
>    движении дел СОЮ (помимо интернет-порталов судов)?
>
> Цель использования — правомерный мониторинг движения судебных дел с участием
> организации (открытые данные, без обхода средств защиты, с соблюдением
> ограничений сервиса). Ориентировочная нагрузка — до нескольких сотен
> запросов в месяц.
>
> С уважением, …
> (должность, организация, контакты)

## Вопросы в юрдеп/комплаенс банка (СПАРК / Контур.Фокус)
