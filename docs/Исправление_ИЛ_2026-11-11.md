# Исправление подтверждённых ошибок контроля ИЛ

Событие портала «Вынесено решение (определение)» само по себе больше не
считается новым решением по существу. Датированные события обычного и
заочного решения сохраняют прежнее поведение. Известный УИД, противоречащий
ответу карточки, останавливает применение её событий и ИЛ; дата успешного
чтения не обновляется. Апелляционный блок сохраняет собственный УИД для
межинстанционной проверки связей.

`scripts/reconcile_writ_evidence.py` выполняет разовое восстановление только
в новом каталоге копии. Вход: полный снимок территории с паспортом и отдельный
пакет проверенных свидетельств `evidence.json` + `html/<sha256>.html`.
Пакет свидетельств и рабочие данные в общий исходный код не включаются.

Скрипт проверяет территорию, хеш HTML, номер, суд, площадку, ссылку и УИД;
заново разбирает HTML без сетевых обращений. Коррекция даты требует текста
акта с проверенным хешем и УИД, совпадающей даты карточки и события решения.
Снятие проверки из-за общего события «решение (определение)» допускается
только при сохранении прежней даты решения в карточке и конкретном событии.
Иные замороженные причины, включая возобновление производства, не снимаются.

Разделение ошибочно связанных дел требует двух самостоятельных записей и
карточки апелляции с подтверждёнными УИД, номером и судом первой инстанции.
Исключённая ошибочная запись, исходные целевые записи и прежние задачи
сохраняются в `writ_repair_log`. Они не помещаются в `history`, чтобы
обычный парсер не возобновил обработку ошибочного производства.

Новые ИЛ добавляются по дате выдачи и идентификатору электронного документа
или бумажного бланка. Старые записи и их статусы не удаляются; свидетельство
не используется для понижения уже сохранённого статуса. Дочитка листов не
меняет `last_checked_at` и не создаёт уведомления о давней выдаче.
Отмена решения, изменение основания, возврат и отзыв сохраняют ручной разбор.

На выходе: новая копия, `writ_repair_report.json`, `manual_review.csv`.
Проверяются неизменность входа, повторный запуск, сохранение bank-events,
повторное чтение JSON и отсутствие возврата исправленных задач в проверку
при составлении обычного плана. Результаты рассылок и посторонние файлы
сравниваются с исходными байтами.

```sh
python scripts/reconcile_writ_evidence.py \
  --input <снимок> --output <новая-копия> --evidence <свидетельства> \
  --region hmao --date 2026-11-11
```

Установка выполняется отдельно: точный пакет программы через
`program_release.py`, затем применение к свежей копии под штатной блокировкой
клона с сохранением резервного архива. Данные публикуются обычным коммитом
без маркера запуска replay. Рабочие расписания и каналы доставки не меняются.
