# Техническая документация

Подробное описание того, **как устроена и как работает** система мониторинга
судебных дел ПАО Сбербанк (суды ХМАО-Югры — 1-я инстанция, апелляция, кассация).

## Для кого это

Документация рассчитана на двух читателей сразу:

- **Юрист-владелец системы** — каждый документ открывается разделом «Что это и
  зачем» простым языком: что система делает, откуда берёт данные, как читать
  результат. Этого раздела достаточно, чтобы понять смысл компонента без кода.
- **Разработчик-преемник**, который будет сопровождать код — дальше идёт
  техническая часть: структуры данных, ключевые функции с путями и номерами
  строк, потоки выполнения, диаграммы.

Если вы быстро ищете «где в коде лежит X» — короткая карта-навигатор для этого
есть в корневом [`CLAUDE.md`](../../CLAUDE.md). Эта папка — полный справочник.

> ℹ️ **Июль 2026: монолит распилен.** Код, который в этих документах
> исторически упоминался как «монолит `update_cases.py`», теперь живёт в пакете
> [`scripts/court_monitor/`](../../scripts/court_monitor/__init__.py)
> (config, textutil, netutil, courts, storage, health, lifecycle, parsing/,
> linking, digest/, delivery, runs); `scripts/update_cases.py` остался тонким
> CLI-фасадом с прежними флагами. Ссылки на код в главах переанкерованы на
> модули; имена функций и поведение не менялись.

> ⚠️ **03.07.2026: временная схема запуска (D2).** Сайты судов начали дропать
> TLS с иностранных IP → парсинг переехал с GitHub Actions на **Mac юриста**
> (LaunchAgent + [`ops/mac-local-run/`](../../ops/mac-local-run/README.md)),
> а Claude-дайджест собирается на GitHub по факту push'а
> (`replay_on_push.yml`); cron Cloudflare Worker'а отключён. Это **временное
> решение — в будущем парсинг переедет на сервер (российский VPS)**, после
> чего главы 01/09/10 нужно будет снова обновить. Детали: [01. Обзор](01-обзор-и-архитектура.md),
> [09. Cloudflare Worker](09-cloudflare-worker.md), [10. CI/CD](10-ci-cd-и-эксплуатация.md).

## Где что лежит в репозитории

```
dashboard/
├── scripts/update_cases.py     # Монолит-бэкенд: парсеры, дайджест, доставка, CLI
├── scripts/add_cases_manually.py
├── data/                       # cases.json + архивы + служебные снимки
├── app.js / sberbank_dashboard.html / styles.css   # SPA-дашборд (GitHub Pages)
├── service-worker.js / manifest.json                # PWA
├── cloudflare-worker/worker.js / wrangler.toml      # API подписок + админка (cron отключён)
├── ops/mac-local-run/          # ⏳ ВРЕМЕННО: парсинг судов на Mac юриста (геоблок)
├── .github/workflows/*.yml     # GitHub Actions (replay_on_push — прод-дайджест)
└── docs/technical/             # ← вы здесь
```
