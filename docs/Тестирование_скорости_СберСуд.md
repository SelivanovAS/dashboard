# Тест скорости: СберСуд против ручного поиска по судам

> Материалы сгенерированы 15.08.2026 (`python3 scripts/make_speed_test.py`).
> Даты заседаний протухают — перегенерировать за день-два до теста.

**Пул:** 10 дел, 30 проверяемых фактов, три инстанции, суды по возможности не повторяются.
Отобраны из рабочей картотеки: 160 активных дел основной картотеки и 512 дел трека «Иски банка».

---

## Регламент

**Задача обоим участникам одна:** по каждому делу из списка найти актуальные сведения и записать их в бланк. Побеждает тот, кто быстрее сдаст бланк — с учётом штрафа за ошибки.

**Участник 1 — СберСуд.** Любые возможности дашборда: поиск, фильтры, карточка дела, дайджест, «Мои дела».

**Участник 2 — ручной поиск.** Только официальные источники: сайты районных и городских судов (ГАС «Правосудие», sudrf.ru), сайт Суда ХМАО-Югры, сайт 7-го кассационного суда. Способ поиска — любой привычный. Нельзя пользоваться СберСудом и коммерческими агрегаторами.

**Условия, одинаковые для обоих:**

- Тест проводится утром рабочего дня, после планового прогона СберСуда (данные обновляются в 08:30 по ХМАО) — иначе преимущество будет нечестным в другую сторону.
- Оба стартуют одновременно по команде наблюдателя, бланки выдаются в закрытом виде и открываются на старте.
- Заранее список дел никому не показывать.
- Интернет, компьютер и браузер — одинаковые по классу; заранее открытые вкладки с сайтами судов не готовить.
- Вопросы наблюдателю по существу дел не задавать; уточнения только по форме бланка.

**Что фиксирует наблюдатель:**

- время старта и время сдачи бланка каждым участником (общее время);
- по возможности — отметку времени после каждого дела: это даёт разбивку «на каких делах разрыв больше всего» (обычно на апелляции и кассации).

## Как считается результат

1. **Чистое время** — от старта до сдачи заполненного бланка.
2. **Точность** — каждый факт сверяется с эталонным листом арбитра (всего фактов: 30).
3. **Штраф** — за каждый неверный или незаполненный факт +2 минуты к времени. Без штрафа участник может выиграть, сдав пустой бланк.
4. **Итог** — чистое время + штраф. Отдельно фиксируется процент верных фактов.

| Показатель | Участник 1 (СберСуд) | Участник 2 (ручной поиск) |
|---|---|---|
| Время старта | | |
| Время сдачи бланка | | |
| Чистое время | | |
| Верных фактов из 30 | | |
| Штраф (ошибок × 2 мин) | | |
| **Итоговое время** | | |

**Важная оговорка про расхождения.** Если ответ СберСуда расходится с карточкой суда, это НЕ ошибка участника: значит, суд обновил карточку после ночного прогона. Такие случаи арбитр отмечает отдельной строкой — для доклада это честный и полезный факт (данные СберСуда отстают максимум на один прогон).

## Заметки для доклада

- Пул подобран программно по типам стадий, а не вручную: «удобные» дела не выбирались. Это стоит проговорить вслух — первый вопрос из зала будет именно про подбор.
- Разрыв ожидаемо растёт на делах в апелляции и кассации: ручному участнику нужно найти дело на сайте другого суда, а связку «первая инстанция → апелляционный номер → кассационный номер» ему приходится восстанавливать самому.
- Полезно записать не только итог, но и то, где ручной участник застревал (капча, поиск по фамилии, дело нашлось не с первого раза) — в докладе это живее любой цифры.
