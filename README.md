# СберСуд — общая программа

Это исходная ветка `codex/program` проекта `SelivanovAS/dashboard`.
Она предназначена для разработки общей программы четырёх территорий.
Рабочая система ХМАО продолжает жить в `main`; региональные сайты и данные
сохраняются в прежних репозиториях.

- [Порядок разработки, выпуска и отката](docs/Общая_программа.md)
- [Правила работы агента](AGENTS.md)
- [Техническая документация](docs/technical/README.md)

Пакет выпуска содержит только управляемые исходники и настройки. Картотеки,
история, очереди, журналы доставки и секреты в исходную ветку не переносятся.
Исходную ветку нельзя объединять с production `main` обычным merge.
